# Lucas Araujo

Software engineer at [Nomad](https://nomadglobal.com), in Campinas. I also founded [Inker](https://inker.me/), a platform for tattoo artists. I built and ran most of it alone, with agents. What I was missing were tools that let them act, stop, ask, and show what happened.

These five are the open-source versions. They speak MCP and CLI, return structured output, and keep state explicit. Decisions that need human context stay with me.

## Selected work

- **[agent-action-gate](https://github.com/lucasaraujonrt/agent-action-gate)** — Approval for an action. An uncertain API result stays uncertain until someone reconciles it. [Site](https://lucasaraujonrt.github.io/agent-action-gate/)
- **[agent-media-jobs](https://github.com/lucasaraujonrt/agent-media-jobs)** — fal.ai jobs with a cost estimate, a spend cap, and a check of the file that comes back. [Site](https://lucasaraujonrt.github.io/agent-media-jobs/)
- **[meta-ops-mcp](https://github.com/lucasaraujonrt/meta-ops-mcp)** — Read Instagram and Meta Ads, and prepare campaign changes for a separate approval. [Site](https://lucasaraujonrt.github.io/meta-ops-mcp/)
- **[agent-task-board](https://github.com/lucasaraujonrt/agent-task-board)** — Create, find, and update tasks from a CLI or MCP. [Site](https://lucasaraujonrt.github.io/agent-task-board/)
- **[agent-unknowns](https://github.com/lucasaraujonrt/agent-unknowns)** — Assumptions and questions before implementation, in an interactive document. [Site](https://lucasaraujonrt.github.io/agent-unknowns/)
