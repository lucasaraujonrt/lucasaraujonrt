# Lucas

Software engineer at Nomad, in Campinas. I build TypeScript tools for coding agents: local state, explicit approval, and at-most-once execution.

## Selected work

- **[agent-unknowns](https://github.com/lucasaraujonrt/agent-unknowns)** — Surfaces what a task leaves unanswered, then turns the answers into something you can paste back into the chat. [Site](https://lucasaraujonrt.github.io/agent-unknowns/)
- **[agent-action-gate](https://github.com/lucasaraujonrt/agent-action-gate)** — Approval and at-most-once dispatch. If a call's result is unknown, it stays unknown until someone reconciles it. [Site](https://lucasaraujonrt.github.io/agent-action-gate/)
- **[agent-task-board](https://github.com/lucasaraujonrt/agent-task-board)** — Local task board on SQLite, with a JSON CLI and an MCP server. [Site](https://lucasaraujonrt.github.io/agent-task-board/)
- **[agent-media-jobs](https://github.com/lucasaraujonrt/agent-media-jobs)** — Paid media jobs with an approval hash, a single submit, and verified file delivery. [Site](https://lucasaraujonrt.github.io/agent-media-jobs/)
- **[meta-ops-mcp](https://github.com/lucasaraujonrt/meta-ops-mcp)** — Scoped Meta Graph tools. Campaign changes require a separate approval. [Site](https://lucasaraujonrt.github.io/meta-ops-mcp/)

Before this, most of the public work was React Native: templates, Reanimated studies, and a finance dashboard at [nrt-dashboard.vercel.app](https://nrt-dashboard.vercel.app).
